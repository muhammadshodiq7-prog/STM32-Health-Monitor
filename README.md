# 健康监测系统 (Health Monitor System)

基于 PyQt6 开发的实时健康数据监测与串口调试工具，支持体温、心率、加速度等生理指标的实时采集、可视化和分析。

## 项目简介

本系统是一个功能完善的健康监测平台，主要特点包括：

- **双标签页设计**：包含"串口助手"和"可视化界面"两个主要功能模块
- **实时数据监测**：支持体温、心率、三轴加速度等生理数据的实时采集和显示
- **智能报警系统**：可根据预设阈值自动触发温度/心率异常报警
- **数据可视化**：提供实时图表展示，支持历史数据回溯
- **健康建议生成**：基于当前生理指标自动生成健康建议
- **数据导入导出**：支持 JSON 格式的数据保存和加载

## 功能模块

### 1. 串口助手 (SerialTab)
- 串口参数配置（端口、波特率、数据位、校验位、停止位）
- ASCII/HEX 格式数据收发
- 支持重复发送功能
- 日志保存和统计信息查看
- 自动串口扫描和刷新

- 数据保存/加载/清空功能

### 运行注意事项

#### 1. 项目结构要求

确保项目目录结构如下：
```
项目根目录/
├── main_pyqt.py          # 主程序入口
├── pyqt_main_window.py   # 主窗口模块
├── monitor_controller.py # 业务逻辑控制器
├── pyqt_serial_tab.py    # 串口助手标签页
├── pyqt_monitor_tab.py   # 监测界面标签页
└── pyqt_realtime_chart.py # 实时图表窗口
```

#### 2. 串口连接说明

- 系统默认扫描 COM4-COM9 串口
- 连接成功后会自动发送 "CONNECT" 命令
- 支持数据格式：
  - `T:36.5,H:75` (温度:心率)
  - `36.5,75` (温度,心率)
  - 单独数值（自动识别温度/心率范围）

#### 3. 串口参数配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| COM端口 | COM7 | 常用端口：COM4-COM9 |
| 波特率 | 9600 | 支持：1200-921600 |
| 数据位 | 8 | 可选：5/6/7/8 |
| 停止位 | 1 | 可选：1/1.5/2 |
| 校验位 | None | 可选：None/Even/Odd |

#### 4. matplotlib 中文字体

系统会自动配置中文字体，优先顺序：
- Microsoft YaHei (Windows)
- SimHei (Windows)
- Arial Unicode MS (macOS)
- DejaVu Sans (Linux)

如遇到中文显示问题，请确保系统安装了相应字体。

#### 5. 报警阈值设置

默认报警阈值（可在代码中修改）：

| 指标 | 最小值 | 最大值 |
|------|--------|--------|
| 体温 | 36.0°C | 37.5°C |
| 心率 | 60 bpm | 120 bpm |

## 数据格式

### 串口数据格式

系统支持多种数据格式：

```
# 格式1：键值对格式
T:36.5,H:75

# 格式2：CSV格式
36.5,75

# 格式3：单独数值
36.5    # 识别为温度
75      # 识别为心率
```

### 数据存储格式

保存的 JSON 数据包含：
```json
{
  "current_data": {...},
  "data_history": [...],
  "statistics": {...},
  "alarm_settings": {...},
  "save_time": "2024-xx-xx"
}
```

## 常见问题

### Q1: 提示"导入模块失败"
**解决方法：**
```bash
pip install pyqt6 pyqtgraph pyserial matplotlib
```

### Q2: 串口连接失败
**解决方法：**
- 检查串口是否被其他程序占用
- 确认串口驱动已正确安装
- 尝试更换串口号或波特率

### Q3: 中文显示为方框
**解决方法：**
- Windows: 确保安装了 "微软雅黑" 字体
- Linux: `sudo apt-get install fonts-wqy-microhei`

### Q4: matplotlib 图表显示异常
**解决方法：**
```bash
pip install --upgrade matplotlib
```

说明：
在本项目的实际调试与测试过程中发现，系统中所使用的部分传感器对外界环境变化较为敏感。在裸露状态下运行时，传感器容易受到轻微振动、电磁干扰以及光照等因素的影响，从而导致采集数据出现异常，影响测量结果的稳定性。
以加速度传感器为例，在实践过程中我发现，设备在桌面轻微晃动或手持操作时，便可能产生明显的数据变化，进而在跌倒监测等功能中引发误判。
因此，在实际使用过程中，有必要对传感器模块进行适当的封装与固定处理，例如通过外壳、减震材料或结构支撑对传感器进行保护与隔离，以减少环境干扰对数据采集的影响。通过封装设计，可以在保证传感器响应能力的同时，提高系统整体运行的稳定性与实用性，使其更符合实际应用需求。
